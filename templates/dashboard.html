📖 Инструкция по программе «ВетГид корпоративный график»

1. Вход в программу

  1. Откройте ссылку, которую выдал администратор (локальная сеть или внешняя).
  2. Введите логин и пароль. Нажмите «Войти».
  3. Откроется главный экран — календарь текущего месяца.

2. Календарь — просмотр графика

  1. Вверху выберите месяц и год, нажмите «Загрузить».
  2. В ячейках дней видны задачи (типы смен) и заметки. Цвета задач задаёт администратор.
  3. Клик по дню — справа откроется панель дня: задачи на этот день, задачи от коллег, файлы. Если панель не видна — прокрутите страницу вправо.
  4. Клавиши: N — следующий месяц, P — предыдущий, T — перейти на сегодня, Enter — открыть меню выбранного дня.
  5. Администратор может отфильтровать календарь по сотруднику (выпадающий список «Все сотрудники»).

3. Работа с конкретным днём

  1. Выберите день в календаре. Справа появятся кнопки и блоки.
  2. «Задачи на день» — поставить себе задачи (чекбоксы), заметки. Сохранить.
  3. «График дня: обзор и действия» — кто в смене, поставить себя/сотрудника в график, поставить задачу коллеге, загрузить файл на этот день.
  4. «Шаблон с другого дня» — скопировать задачи и заметки с другого числа этого месяца.
  5. В панели дня видны «Задачи от коллег / мне» и «Файлы на этот день» — можно открывать и скачивать.

4. Раздел «Задачи» (типы смен)

  1. Меню → Задачи. Здесь список типов смен (например «Утро», «Ревизия», «Закрытие»).
  2. Добавлять и менять типы задач может только администратор. Сотрудники только выбирают их в своём дне.

5. Раздел «Файлы»

  1. Меню → Файлы. Можно загружать файлы и фото (до 50 МБ), привязывая к дате (год, месяц, день).
  2. Удобно загружать с телефона: выберите день, нажмите «Загрузить файл», выберите фото или PDF.
  3. Файлы можно переименовать, изменить дату или удалить (свои — всегда, чужие — только админ).

6. Чат и Telegram

  1. Меню → Чат. Темы создаёт администратор. Сообщения видны всем, кто имеет доступ к теме.
  2. Тема «Telegram» — сообщения из неё автоматически отправляются в группу Telegram (если настроен бот).
  3. При новых сообщениях в чате браузер может запросить разрешение на уведомления — удобно не пропускать сообщения.

7. Рабочий журнал

  1. Меню → Рабочий журнал. Записи по сменам: открытие (утро, касса), записи за день, закрытие (вечер, безнал, чеки, Z-отчёт).
  2. Сотрудник видит только те дни, когда он есть в графике. Администратор видит все смены.
  3. Открыть смену → вносить записи → закрыть смену (при необходимости приложить файлы чеков).

8. Админ-панель (только для администратора)

  1. Меню → Админ-панель. Здесь: список пользователей (добавить/удалить), статистика, привязка участников Telegram к пользователям.
  2. Участники Telegram — кнопка «Загрузить участников из группы» подтягивает тех, кто писал в группу; можно привязать Telegram-аккаунт к сотруднику, чтобы фото из группы сохранялись в его смену.

9. Печать и доступ с телефона

  1. Печать (PDF) — кнопка в шапке календаря. Откроется печать браузера, можно сохранить страницу как PDF.
  2. Для входа с телефона или из другой сети используйте ссылку, которую присылают в Telegram при запуске программы (или из файла ВНЕШНИЙ_ДОСТУП.txt).
