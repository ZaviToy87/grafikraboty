## 🐛 ВОЗМОЖНЫЕ ПРОБЛЕМЫ

### Docker не запускается

**Проблема:** Docker не найден  
**Решение:** Перезагрузить компьютер, проверить Docker Desktop

### Ошибка "port already in use"

**Проблема:** Порт 8080 занят  
**Решение:** Изменить порт в `docker-compose.yml`:
```yaml
ports:
  - "8081:8080"
```

### PWA не устанавливается

**Проблема:** Требуется HTTPS  
**Решение:** Для production нужен SSL сертификат

### Сканер не работает

**Проблема:** Требуется HTTPS для камеры  
**Решение:** Использовать HTTPS или localhost
