# ИСПРАВЛЕНИЕ ШТРИХ-КОДЕРА В РЕВИЗИИ ТОВАРОВ (07.04.2026)

## ПРОБЛЕМА
Штрих-кодер не работает в ревизии товаров:
1. COM-сканер не подключается — ошибка "Permission denied" на COM6
2. При сканировании товар не ищется автоматически в базе 1С
3. Поля не заполняются автоматически

## ЧТО ИСПРАВЛЕНО

### 1. ✅ Авто-поиск товара в 1С при сканировании
**Файл:** `templates/dashboard.html`

**Что добавлено:**
- Функция `autoSearchProductByBarcode(barcode)` — ищет товар в базе 1C по штрих-коду
- Автоматическое заполнение всех полей при сканировании:
  - Наименование товара (`rev-product-name`)
  - Штрих-код (`rev-barcode`)
  - Розничная цена (`rev-retail-price`)
- Визуальное подтверждение (зелёная подсветка полей)
- Звуковой сигнал при сканировании
- Уведомление о результате поиска (найден/не найден/ошибка)

**Как работает:**
1. Сотрудник сканирует штрих-код сканером
2. Система получает штрих-код из `/api/com-scanner/last`
3. **НОВОЕ:** Автоматически ищет товар в 1C по штрих-коду
4. **НОВОЕ:** Если товар найден — заполняет все поля (название, цена)
5. **НОВОЕ:** Если товар не найден — показывает предупреждение
6. Сотруднику остаётся ввести только количество и срок годности

### 2. ✅ Улучшенный UI при сканировании
**Зелёное уведомление** когда товар найден:

## КАК ИСПОЛЬЗОВАТЬ

### Шаг 1: Проверка COM-портов
Запустите диагностику:
```bash
python diagnose_com_ports.py
```

Вы увидите все доступные COM-порты. Если сканер подключён но порт не определяется:
- Переподключите сканер в другой USB
- Проверьте диспетчер устройств Windows
- Установите драйверы сканера

### Шаг 2: Настройка COM-порта
Если сканер на другом порту (не COM6), измените в `com_scanner.py`:

```python
COM_PORTS = {
    'scanner_2': {'port': 'COM6', 'baudrate': 9600, 'name': 'Сканер 2 (Основной)'},
    # Измените 'COM6' на нужный порт, например 'COM3', 'COM4' и т.д.
}
```

### Шаг 3: Запуск сервера
```bash
python web_server.py
```

Или используйте батник:
```bash
ЗАПУСТИТЬ_СЕРВЕР.bat
```

### Шаг 4: Работа с ревизией

1. **Откройте ревизию:** Меню → 📦 Ревизия товара
2. **Нажмите:** ➕ Добавить товар
3. **Включите сканер:** Нажмите кнопку "Сканер выключен" (станет зелёной)
4. **Сканируйте штрих-код:** Наведите сканер на товар
5. **Авто-заполнение:** Система автоматически найдёт товар в 1C и заполнит поля
6. **Введите остаток:** Количество и срок годности
7. **Сохраните:** Нажмите "Добавить"

## API ENDPOINTS

### GET /api/com-scanner/last
Получить последний отсканированный штрих-код

**Ответ:**
```json
{
  "status": "success",
  "data": {
    "barcode": "4607027763890",
    "timestamp": "2026-04-07T14:30:00.123456"
  }
}
```

### GET /api/products-1c/barcode/<barcode>
Найти товар по штрих-коду в базе 1C

**Ответ (успех):**
```json
{
  "status": "success",
  "product": {
    "id": 123,
    "name": "Молоко Простоквашино 3.2%",
    "barcode_main": "4607027763890",
    "retail_price": 89.50,
    "group_name": "Молочные продукты"
  }
}
```

**Ответ (не найдено):**
```json
{
  "status": "not_found",
  "message": "Товар по штрих-коду не найден"
}
```

## УСТРАНЕНИЕ ПРОБЛЕМ

### COM-сканер не подключается
**Симптом:** "Permission denied" или "Access denied"

**Решение:**
1. Закройте 1С и другие программы использующие COM-порты
2. Запустите `python diagnose_com_ports.py` — проверьте доступные порты
3. Если порт занят — измените в `com_scanner.py` на свободный
4. Перезапустите сервер

### Товар не ищется автоматически
**Симптом:** Сканирует но не заполняет поля

**Решение:**
1. Проверьте что товары импортированы из 1C:
   ```bash
   python import_1c_products.py
   ```
2. Проверьте что штрих-код есть в базе:
   ```sql
   SELECT * FROM products_1c WHERE barcode_main = '4607027763890';
   ```
3. Откройте консоль браузера (F12) — там будут логи поиска

### Поля не заполняются
**Симптом:** Товар найден но поля пустые

**Решение:**
1. Откройте консоль браузера (F12) — проверьте ошибки JavaScript
2. Очистите кэш браузера (Ctrl+Shift+Delete)
3. Обновите страницу с полной перезагрузкой (Ctrl+F5)

## СЛЕДУЮЩИЕ ШАГИ

Если COM-сканер всё ещё не работает:

1. **Проверьте физическое подключение:**
   - Переподключите сканер в другой USB порт
   - Проверьте диспетчер устройств Windows

2. **Проверьте драйверы:**
   - Скачайте драйверы с сайта производителя сканера
   - Установите их

3. **Используйте ручной ввод:**
   - Введите штрих-код вручную в поле "Внутренний штрих-код"
   - Или используйте поиск по названию в поле поиска 1C

4. **Импорт товаров из 1C:**
   ```bash
   python import_1c_products.py
   ```
   - Положите 2 Excel файла в папку проекта
   - Скрипт обновит базу данных
