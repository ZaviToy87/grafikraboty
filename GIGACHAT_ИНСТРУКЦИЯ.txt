Для добавления GigaChat в веб-интерфейс:

1. Открой web_server.py

2. Добавь импорт:
   import gigachat_api

3. Создай endpoint:
   
   @app.route('/api/gigachat', methods=['POST'])
   def gigachat_endpoint():
       data = request.json
       message = data.get('message', '')
       
       response = gigachat_api.chat([
           {"role": "user", "content": message}
       ])
       
       return jsonify({'response': response or 'Ошибка'})

4. Добавь кнопку в интерфейс

Для использования в VS Code:

1. Установи расширение "Continue"

2. Открой настройки Continue (Ctrl+,)

3. Выбери модель "GigaChat" или "GigaChat Pro"

4. Используй для:
   - Автодополнения кода
   - Чата с AI
   - Рефакторинга
