# 📢 НАПОМИНАНИЯ С ПОДТВЕРЖДЕНИЕМ — ИНСТРУКЦИЯ

## 🎯 Назначение

Система всплывающих напоминаний с обязательным подтверждением прочтения. Позволяет:
- Отправлять важные уведомления сотрудникам
- Требовать подтверждения («Прочитано и понятно»)
- Получать отчёт кто подтвердил, а кто нет
- Автоматически создавать напоминания при просрочке товара

---

## 👤 ДЛЯ СОТРУДНИКА

### 1. Получение напоминания

**При входе в систему:**
1. Через 2 секунды после загрузки страницы появляется всплывающее окно
2. Окно **НЕЛЬЗЯ закрыть** просто так (клик вне окна не работает)
3. **ОБЯЗАТЕЛЬНО** нужно нажать кнопку **«✅ ПРОЧИТАНО И ПОНЯТНО»**

**Внешний вид окна:**
```
┌──────────────────────────────────────┐
│ 📢 ВАЖНОЕ НАПОМИНАНИЕ            × │
├──────────────────────────────────────┤
│                                      │
│  ⚠️ Просрочка: Молоко 3.2%          │
│                                      │
│  Товар «Молоко 3.2%» просрочен      │
│  (01.04.2026). Необходимо:          │
│  1. Проверить наличие               │
│  2. Утилизировать                   │
│  3. Отметить в системе              │
│                                      │
│  📊 Статус: 2 из 3 сотрудников      │
│      подтвердили                    │
│                                      │
│  Дата: 01.04.2026 09:00 |           │
│  Тип: ⚠️ Ревизия                    │
│                                      │
├──────────────────────────────────────┤
│  ✅ ПРОЧИТАНО И ПОНЯТНО              │
│                                      │
│  ⚠️ Вы должны подтвердить прочтение │
└──────────────────────────────────────┘
```

### 2. Подтверждение

1. Прочитайте напоминание
2. Нажмите **«✅ ПРОЧИТАНО И ПОНЯТНО»**
3. Если есть ещё напоминания — откроется следующее
4. Если все прочитаны — появится сообщение «✅ Спасибо!»

### 3. Если напоминаний несколько

Окна показываются **по очереди**:
1. Подтвердили первое → открывается второе
2. Подтвердили второе → открывается третье
3. И так далее

## 👨‍ ДЛЯ АДМИНИСТРАТОРА

### 1. Создать напоминание вручную

1. Откройте **«Админ-панель»**
2. Нажмите **«📢 Создать напоминание»**
3. Заполните форму:
   - **Заголовок** — кратко (например, «Проверка холодильников»)
   - **Текст** — подробно что нужно сделать
   - **Тип** — общее/ревизия/график/задача
   - **Требуется подтверждение** — галочка (обычно включено)
   - **Срок действия** — через сколько часов истечёт (необязательно)
4. Нажмите **«Создать и отправить»**

**Что происходит:**
- Напоминание сохраняется в БД
- Отправляется уведомление в VK чат
- Сотрудники видят окно при следующем входе

### 2. Посмотреть статистику

**API для просмотра:**
```
GET /api/reminders/<id>/stats
```

**Ответ:**
```json
{
  "reminder": {
    "title": "Проверка холодильников",
    "total_users": 3,
    "confirmed_users": 2
  },
  "confirmed": [
    {"full_name": "Иванова М.", "confirmed_at": "2026-04-01 09:15:00"},
    {"full_name": "Петрова А.", "confirmed_at": "2026-04-01 09:20:00"}
  ],
  "not_confirmed": [
    {"full_name": "Сидорова Е."}
  ],
  "progress": "2/3"
}
```

**Через VK бота:**
- Когда все подтвердили — админ получает отчёт в личку
- Список кто подтвердил + время

### 3. Удалить напоминание

**API:**
```
DELETE /api/reminders/<id>
```

Окно больше не будет показываться.

## 🤖 АВТОМАТИЧЕСКИЕ НАПОМИНАНИЯ

### При просрочке товара

Когда товар просрочивается (ежедневная проверка в 9:00):

1. **Создаётся напоминание** автоматически
   - Заголовок: «⚠️ Просрочка: [Товар]»
   - Текст: что нужно сделать
   - Срок действия: 7 дней
   - Требуется подтверждение: ✅

2. **Отправляется в VK чат**

3. **Сотрудники видят окно** при входе

4. **Админ получает отчёт** когда все подтвердили

## 🔗 API ENDPOINTS

```
# Получить напоминания пользователя
GET /api/reminders

# Подтвердить напоминание
POST /api/reminders/<id>/confirm

# Создать напоминание (админ)
POST /api/reminders

  "title": "Заголовок",

  "type": "general|revision|schedule|task",
  "require_confirmation": true,
  "expires_hours": 24
}

# Статистика напоминания (админ)
GET /api/reminders/<id>/stats

# Удалить напоминание (админ)
DELETE /api/reminders/<id>
```

## 🗄️ БАЗА ДАННЫХ

### Таблица `reminders`
```sql
CREATE TABLE reminders (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    message TEXT NOT NULL,
    created_by INTEGER,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    reminder_type TEXT DEFAULT 'general',
    expires_at TIMESTAMP,
    require_confirmation INTEGER DEFAULT 1,
    
    total_users INTEGER DEFAULT 0,
    confirmed_users INTEGER DEFAULT 0,
    
    is_active INTEGER DEFAULT 1
)
```

### Таблица `reminder_confirmations`
```sql
CREATE TABLE reminder_confirmations (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    reminder_id INTEGER NOT NULL,
    user_id INTEGER NOT NULL,
    confirmed_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (reminder_id) REFERENCES reminders(id),
    FOREIGN KEY (user_id) REFERENCES users(id),
    UNIQUE(reminder_id, user_id)
)
```

## ⚠️ ВАЖНО

1. **Нельзя закрыть без подтверждения** — окно будет висеть пока не нажмёшь кнопку
2. **Напоминания показываются при каждом входе** пока не подтвердишь
3. **Админ видит кто подтвердил** в реальном времени
4. **VK отчёт приходит** когда ВСЕ подтвердили

## 🎨 ВИЗУАЛЬНЫЙ СТИЛЬ
