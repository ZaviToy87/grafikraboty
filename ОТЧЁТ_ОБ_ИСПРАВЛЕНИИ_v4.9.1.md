## 🎯 ПРИЧИНЫ ПРОБЛЕМ

### 1. Все смены "Закрыты" с нулевыми суммами

**Причина:** При миграции все старые смены были автоматически помечены как `closed` с суммами 0.0, потому что:
- В старых данных не было записей об открытии/закрытии
- Миграция создала `work_sessions` на основе записей в `work_journal_entries`
- Для старых смен записей не было → суммы = 0

**Решение:** Эти "закрытые" смены — исторические данные. Новые смены будут создаваться сотрудниками через интерфейс.

### 2. Календарь пустой

**Причина:** API `/api/schedule` использовало старое имя таблицы `schedule` вместо `work_schedule`.

**Решение:** Исправлены все SQL запросы в `web_api.py`.

### 3. Ошибка загрузки данных

**Причина:** Возможно, проблема с JavaScript кэшем или API.

**Решение:** Обновлена версия CSS/JS для сброса кэша.
