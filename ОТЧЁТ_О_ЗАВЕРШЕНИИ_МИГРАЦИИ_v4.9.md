## 📊 НОВАЯ СТРУКТУРА БД

### work_schedule (график работы)
**Назначение:** Планируемое расписание — кто ДОЛЖЕН работать

```sql
CREATE TABLE work_schedule (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    year INTEGER NOT NULL,
    month INTEGER NOT NULL,
    day INTEGER NOT NULL,
    task_ids TEXT DEFAULT '[]',
    notes TEXT,
    created_at TIMESTAMP,
    updated_at TIMESTAMP,
    UNIQUE(user_id, year, month, day)
);
```

**Данные:** 31 запись

### work_sessions (фактические смены)
**Назначение:** Фактически отработанное время — кто РЕАЛЬНО работал

```sql
CREATE TABLE work_sessions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    work_schedule_id INTEGER,  -- Связь с графиком
    year INTEGER NOT NULL,
    month INTEGER NOT NULL,
    day INTEGER NOT NULL,
    opened_at TIMESTAMP,
    closed_at TIMESTAMP,
    opening_sum REAL DEFAULT 0,
    closing_sum REAL DEFAULT 0,
    revenue_total REAL DEFAULT 0,
    acquiring_amount REAL DEFAULT 0,
    evening_cash REAL DEFAULT 0,
    evening_cashless REAL DEFAULT 0,
    notes TEXT,
    status TEXT DEFAULT 'opened',  -- 'opened' | 'closed'
    created_at TIMESTAMP,
    updated_at TIMESTAMP
);
```

**Данные:** 31 запись

**Индексы:**
- `idx_work_sessions_user` — по user_id
- `idx_work_sessions_date` — по year, month, day
- `idx_work_sessions_status` — по status

### work_journal_entries (записи журнала)
**Назначение:** Операции в смене (открытие, закрытие, продажи, расходы)

```sql
CREATE TABLE work_journal_entries (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    shift_id INTEGER NOT NULL,  -- Ссылка на work_sessions.id
    kind TEXT NOT NULL,  -- 'opening' | 'closing' | 'sale' | 'expense'
    amount REAL,
    note TEXT,
    created_at TIMESTAMP,
    user_id INTEGER
);
```

**Данные:** 2 записи

**Индексы:**
- `idx_wje_shift` — по shift_id
- `idx_wje_kind` — по kind
