# ИСПРАВЛЕНИЯ VK УВЕДОМЛЕНИЙ v4.21 (25.03.2026)

## ПРОБЛЕМЫ КОТОРЫЕ БЫЛИ ИСПРАВЛЕНЫ:

### 1. ❌ Открытие смены — сумма 0 вместо фактической
**Проблема:** При открытии смены администратор получал сообщение с суммой 0 руб., хотя фактически смена открывалась с суммой 6 857.00 руб.

**Причина:** В `web_work_journal.py` использовался ключ `'opening_sum'`, а в `vk_bot.py` ожидался `'morning_cash'`.

**Исправление:**
- `web_work_journal.py` строка 233: изменён ключ с `'opening_sum': opening_sum` на `'morning_cash': opening_sum`
- `vk_bot.py` использует правильное значение из `shift_data.get('morning_cash', 0)`

**Файлы:**
- `web_work_journal.py` (строка 233)
- `vk_bot.py` (строка 1041)
- `dist/GrafikRaboty_Server/_internal/vk_bot.py` (строка 1033)

### 2. ❌ Дублирование уведомлений при запуске сервера
**Проблема:** При запуске сервера приходило 2+ одинаковых уведомления в VK (и в группу, и в личку админу по 2 раза).

**Причина:** 
- `launcher_with_vk.py` отправляет уведомление через `vk_startup.send_vk_startup_notification()`
- `main_launcher.py` (который запускается в потоке) ТОЖЕ отправляет через `_send_vk_startup_notification()`
- Итого: 2 вызова = 2 сообщения × 2 адреса (группа + админ) = 4 сообщения

**Исправление:**
- В `main_launcher.py` отключено VK уведомление в функции `_notify_telegram_and_hint()`
- Добавлен флаг `VK_NOTIFICATION_ENABLED = False` (можно включить если нужно)
- Теперь уведомление отправляется ТОЛЬКО из `launcher_with_vk.py`

**Файлы:**
- `main_launcher.py` (строки 1470-1478)

---

### 3. ❌ Дублирование уведомлений об открытии/закрытии смены
**Проблема:** При открытии/закрытии смены могло прийти несколько одинаковых уведомлений администратору.

**Причина:** Отсутствие rate limiting — функция `send_shift_notification()` вызывалась каждый раз без проверки частоты.

**Исправление:**
- Добавлен глобальный словарь `_shift_notification_cooldown` для отслеживания последних уведомлений
- Добавлена константа `_SHIFT_NOTIFICATION_COOLDOWN_SEC = 60` (1 минута между уведомлениями)
- Функция `send_shift_notification()` теперь проверяет: если такое же уведомление (user + action) было отправлено менее 60 секунд назад — пропускает
- Логирование: `Shift notification skipped (cooldown)` при пропуске

**Файлы:**
- `vk_bot.py` (строки 56-57, 1019-1051)
- `dist/GrafikRaboty_Server/_internal/vk_bot.py` (строки 56-57, 993-1025)

✅ **1 сообщение при запуске сервера** — в группу сообщества + в личку админу (всего 2, но не 4+)

✅ **1 сообщение при открытии смены** — администратору в личку, с ПРАВИЛЬНОЙ суммой

✅ **1 сообщение при закрытии смены** — администратору в личку, с полным отчётом

## ТЕСТИРОВАНИЕ:

1. **Запуск сервера:**
   ```bash
   python launcher_with_vk.py
   ```
   Ожидается: 1 сообщение в группу + 1 в личку админу (всего 2)

2. **Открытие смены:**
   - Открыть смену через веб-интерфейс
   - Ожидается: 1 сообщение админу с суммой (не 0!)

3. **Повторное открытие смены (в течение 60 сек):**
   - Открыть смену ещё раз
   - Ожидается: сообщение НЕ отправится (cooldown)

4. **Закрытие смены:**
   - Закрыть смену через веб-интерфейс
   - Ожидается: 1 сообщение админу с полным отчётом
