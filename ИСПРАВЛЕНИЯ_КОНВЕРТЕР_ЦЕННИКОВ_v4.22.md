# ИСПРАВЛЕНИЯ КОНВЕРТЕРА ЦЕННИКОВ v4.22 (25.03.2026)

## ПРОБЛЕМА

**Задача:** Сделать так, чтобы каждый ценник имел **одну цельную жирную рамку** по периметру (4 строки × 4 колонки), а **внутри ценника не было сетки** — для удобной резки после печати.

**Было:** 
- Применялась жирная рамка `thick_border_all` ко всем 4 строкам ценника
- Из-за этого внутри ценника появлялись горизонтальные разделительные линии
- Ценник нельзя было ровно отрезать — мешали внутренние границы

**Проблема после первого исправления:**
- Боковые границы пропадали у некоторых ценников
- Excel применяет границы только к первой ячейке в объединённом диапазоне (`merge_cells`)

**Стало:**
- **Внешняя рамка** — жирная по всему периметру ценника (все 4 стороны)
- **Внутри ценника** — НЕТ границ (только текст)
- Ценник можно ровно отрезать по жирной внешней рамке

### Файл: `web_converter.py` (строки 303-405)

#### 1. Новая функция для применения границ к объединённым ячейкам

**Проблема:** При использовании `ws.merge_cells()` Excel применяет границы только к **первой ячейке** в диапазоне. Из-за этого боковые границы терялись.

**Решение:** Создана функция `apply_border_to_merged_range()`, которая:
1. Объединяет ячейки
2. Применяет границы к **каждой ячейке** в объединённом диапазоне индивидуально
3. Определяет позицию ячейки (верх/низ/лево/право) и применяет соответствующую границу

```python
def apply_border_to_merged_range(start_row, start_col, end_row, end_col, border_top, border_middle, border_bottom):
    """
    Применить границы к объединённому диапазону ячеек.
    border_top - для первой строки, border_bottom - для последней, border_middle - для средних
    """
    # Сначала объединяем ячейки
    ws.merge_cells(start_row=start_row, start_column=start_col, end_row=end_row, end_column=end_col)
    
    # Применяем границы к каждой ячейке в диапазоне
    for row in range(start_row, end_row + 1):
        for col in range(start_col, end_col + 1):
            cell = ws.cell(row=row, column=col)
            
            # Определяем позицию ячейки в объединённом диапазоне
            is_first_row = (row == start_row)
            is_last_row = (row == end_row)
            is_first_col = (col == start_col)
            is_last_col = (col == end_col)
            
            # Создаём индивидуальную границу для этой ячейки
            left_style = 'thick' if is_first_col else None
            right_style = 'thick' if is_last_col else None
            top_style = 'thick' if is_first_row else None
            bottom_style = 'thick' if is_last_row else None
            
            cell.border = Border(
                left=Side(style=left_style),
                right=Side(style=right_style),
                top=Side(style=top_style),
                bottom=Side(style=bottom_style)
            )
```

#### 2. Новые стили границ

```python
# Боковые границы (для всех ячеек)
thick_border_sides = Border(
    left=Side(style='thick'),
    right=Side(style='thick'),
    top=Side(style=None),
    bottom=Side(style=None)
)

# Верхняя граница (для первой строки ценника)
thick_border_top = Border(
    left=Side(style='thick'),
    right=Side(style='thick'),
    top=Side(style='thick'),
    bottom=Side(style=None)
)

# Нижняя граница (для последней строки ценника)
thick_border_bottom = Border(
    left=Side(style='thick'),
    right=Side(style='thick'),
    top=Side(style=None),
    bottom=Side(style='thick')
)
```

#### 3. Применение границ к строкам ценника

```python
# 1. Организация (верхняя строка) - жирная рамка сверху и по бокам
apply_border_to_merged_range(base_row, base_col, base_row, base_col+3, 
    thick_border_top, thick_border_sides, thick_border_sides)

# 2. Наименование товара (средняя строка) - только боковые
apply_border_to_merged_range(base_row + 1, base_col, base_row + 1, base_col+3, 
    thick_border_sides, thick_border_sides, thick_border_sides)

# 3. Цена (средняя строка) - только боковые
apply_border_to_merged_range(base_row + 2, base_col, base_row + 2, base_col+3, 
    thick_border_sides, thick_border_sides, thick_border_sides)

# 4. Дата (нижняя строка) - жирная рамка снизу и по бокам
apply_border_to_merged_range(base_row + 3, base_col, base_row + 3, base_col+3, 
    thick_border_sides, thick_border_sides, thick_border_bottom)
```
