Кратко
- Этот проект содержит Python-скрипт convert.py для конвертации/обработки файлов ценников или прайс-листов.
- Репозиторий подготовлен к оформлению в полноценный проект: добавим зависимости, удобный запуск, структуру каталогов.

Требования
- Windows 10/11 (подразумевается, но скрипт должен работать и на других ОС)
- Python 3.8+ установлен в системе (проверьте командой python --version)

Структура (текущее состояние)
- convert.py — основной скрипт
- 1111.xlsx — пример/входные данные (образец)
- README.md — документация проекта (этот файл)

Установка окру��ения
1) Рекомендуется создать виртуальное окружение (опционально):
   - python -m venv .venv
   - .venv\\Scripts\\activate

2) Установите зависимости (как только будут добавлены):
   - pip install -r requirements.txt

Запуск
- Базовый вариант:
  - python convert.py

- После добавления удобного сценария запуска в Windows можно будет запускать двойным кликом run_convert.bat.

Примечание по аргументам
- Если convert.py ожидает аргументы (пути к файлам, режимы и т.п.), используйте схему:
  - python convert.py <аргументы>
- Конкретика по аргументам будет описана после анализа кода и добавления CLI-обертки.

План развития проекта
- Добавить .gitignore и requirements.txt
- Определить фактические зависимости из convert.py и зафиксировать их в requirements.txt
- Создать удобный сценарий запуска: run_convert.bat (Windows)
- Структурировать проект (при необходимости):
  - src/price_converter/ — исходники (перенос convert.py внутрь пакета)
  - data/ — входные данные
  - output/ — результаты
  - tests/ — автотесты
- Оформить CLI через pyproject.toml с точкой входа (консольная команда price-convert)

Диагностика проблем
- Если при запуске python convert.py возникает ошибка ModuleNotFoundError, значит отсутствуют зависимости — их следует добавить в requirements.txt и установить через pip
- Для проблем с кодировкой Excel/CSV укажите явно кодировку в скрипте (будет решено при последующей доработке)

Лицензия
