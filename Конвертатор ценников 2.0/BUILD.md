Краткие шаги:
1) Откройте PowerShell или cmd и перейдите в папку проекта:
   cd "c:\Users\User\Desktop\Обучение\Конвертатор ценников 2.0"

2) (Опционально) создайте виртуальное окружение и активируйте его:
   python -m venv .venv
   .venv\Scripts\activate

3) Установите зависимости и pyinstaller:
   pip install --upgrade pip
   pip install pyinstaller openpyxl

4) Соберите exe (GUI-приложение, без консоли):
   pyinstaller --onefile --noconsole --name "КонвертерЦенников" app.py

   Результат: dist\КонвертерЦенников.exe

5) Тестирование: запустите dist\КонвертерЦенников.exe на той же ОС.

Советы при проблемах:
- Если приложение не запускается из-за Tkinter (отсутствие DLL), соберите на той же системе/версии Python, где запускается dev-окружение.
- Для включения дополнительных файлов или папок используйте:
  --add-data "путь\к\файлу;цел_папка_в_пакете" (Windows; разделитель ;)
  или
  --add-binary "путь\к\dll;целевая_папка"
- Для отладки уберите --noconsole, чтобы видеть ошибки.
- Если нужна иконка: --icon="путь\к\icon.ico"
