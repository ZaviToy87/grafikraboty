# 📊 Умная система ревизии товаров - Установка и настройка

## 🎯 Обзор системы

**Умная система ревизии** добавляет к существующей системе ревизии товаров:

1. **Расширенную статистику** по всем типам операций
2. **Умные напоминания** с автоматическими триггерами
3. **Автоматические отчеты** в VK чат
4. **Персональные уведомления** для продавцов
5. **Панель управления** с аналитикой

## 📋 Требования

- Python 3.7+
- Flask
- SQLite3
- Существующая система GrafikRaboty с модулем ревизии

## 🚀 Быстрая установка

### 1. Создание таблиц в базе данных

```bash
python create_smart_revision_tables.py
```

### 2. Интеграция с web_server.py

Добавьте в файл `web_server.py`:

```python
# В начале файла добавьте импорт
from smart_revision_system import smart_bp

# После создания app добавьте blueprint
app.register_blueprint(smart_bp, url_prefix='/smart')
```

### 3. Добавление CSS и JavaScript

Добавьте в `templates/base.html` или в шаблон страницы ревизии:

```html
<!-- В секции head -->
<link rel="stylesheet" href="{{ url_for('static', filename='css/smart_revision.css') }}">

<!-- В конце body -->
<script src="{{ url_for('static', filename='js/smart_revision.js') }}"></script>
```

### 4. Запуск планировщика (опционально)

Для автоматических проверок и отчетов:

```bash
# Ручная проверка
python smart_revision_scheduler.py --manual

# Запуск планировщика в фоне
python smart_revision_scheduler.py --start
```

## 🔧 Конфигурация

### Настройка умных напоминаний

В файле `smart_revision_system.py` можно настроить:

```python
REMINDER_CONFIG = {
    'expiring_soon_days': 7,           # Напоминать за 7 дней до истечения
    'high_discount_threshold': 40,     # Скидка 40%+ считается высокой
    'stale_days': 14,                  # Товар считается "залежавшимся" если не продается 14 дней
    'daily_check_hour': 9,             # Ежедневная проверка в 9:00
    'weekly_report_day': 0,            # 0=Понедельник, еженедельный отчет
}
```

### Настройка VK уведомлений

Убедитесь, что в `vk_config.json` есть:

```json
{
    "admin_vk_id": "ID_администратора",
    "chat_peer_id": "ID_чата_для_отчетов"
}
```

## 📊 API эндпоинты

### Статистика
- `GET /smart/stats?period=30&user_id=1` - Получить статистику за период
- `GET /smart/dashboard` - Панель управления
- `GET /smart/report?period=7` - Умный отчет

### Напоминания
- `GET /smart/reminders?status=pending` - Получить напоминания
- `POST /smart/reminders/{id}/complete` - Отметить как выполненное
- `POST /smart/check-reminders` - Запустить проверку (админ)

## 🎨 Интерфейс

### Кнопки и элементы
1. **Кнопка "Умная статистика"** - появляется на странице ревизии
2. **Бейдж напоминаний** - в правом верхнем углу (если есть активные)
3. **Умная панель** - под основной статистикой ревизии

### Модальные окна
1. **Напоминания** - список активных напоминаний с действиями
2. **Расширенная статистика** - детальная статистика за период
3. **Ежедневные отчеты** - автоматически в VK чат

## ⚙️ Интеграция с планировщиком

### Автоматический запуск
Добавьте в `server_launcher.py` или `main_launcher.py`:

```python
# Импорт планировщика
from smart_revision_scheduler import setup_smart_scheduler

# Запуск планировщика в отдельном потоке
import threading
scheduler_thread = threading.Thread(target=setup_smart_scheduler, daemon=True)
scheduler_thread.start()
```

### Ручной запуск
```bash
# Запустить планировщик
python smart_revision_scheduler.py --start

# Ручная проверка
python smart_revision_scheduler.py --manual

# Тестовая проверка
python smart_revision_scheduler.py --test
```

## 🐛 Устранение неполадок

### Проблема: Таблицы не создаются
**Решение:** Проверьте права доступа к базе данных и путь к `schedule.db`

### Проблема: API возвращает ошибки 404
**Решение:** Убедитесь, что blueprint зарегистрирован в `web_server.py`

### Проблема: Не появляется кнопка в интерфейсе
**Решение:** Проверьте, что JavaScript файл загружается и нет ошибок в консоли

### Проблема: Напоминания не создаются
**Решение:** Проверьте данные в таблицах `product_revisions` и `revision_transactions`
