# ИСПРАВЛЕНИЯ КОНВЕРТЕРА ЦЕННИКОВ v4.23 — ФИНАЛЬНОЕ (25.03.2026)

## ПРОБЛЕМА

**Задача:** Сделать так, чтобы каждый ценник был **единым целым** (4 строки × 4 колонки) с **одной жирной рамкой по периметру**, без внутренних границ.

**Предыдущие попытки:**
1. ❌ Первая попытка: `thick_border_all` ко всем строкам — появились горизонтальные линии внутри ценника
2. ❌ Вторая попытка: `thick_border_top/middle/bottom` — боковые границы пропадали
3. ❌ Третья попытка: применение границ к каждой ячейке — **двойные рамки** между ценниками и горизонтальные линии внутри

**Проблема на скриншоте:**
- Каждый из 4 строк ценника имеет **собственную рамку**
- Внутри ценника видны **горизонтальные разделительные линии**
- Между соседними ценниками **двойные вертикальные линии**

**Причина:** Функция применяла границы к **каждой ячейке** в объединённом диапазоне, вместо того чтобы применить одну границу к **объединённой ячейке**.

**Стало (ФИНАЛ):**
- **Одна жирная рамка** по периметру всего ценника (4 строки × 4 колонки)
- **Внутри ценника** — НЕТ границ вообще
- Между соседними ценниками — **одна общая жирная линия** (не двойная)

## ИСПРАВЛЕНИЯ

### Файл: `web_converter.py` (строки 298-375)

#### 1. Упрощённая функция для применения границ

**Проблема предыдущей версии:** Границы применялись к каждой ячейке в диапазоне (цикл по всем ячейкам), что создавало двойные линии.

**Решение:** Применять границы **только к объединённой ячейке** как к единому целому.

```python
def apply_border_to_merged_range(start_row, start_col, end_row, end_col, is_top, is_bottom):
    """
    Применить границы к объединённому диапазону ячеек.
    Границы применяются только к ВНЕШНИМ ячейкам диапазона.
    
    Args:
        start_row, start_col: Начальная ячейка
        end_row, end_col: Конечная ячейка
        is_top: True если это верхняя строка ценника (нужна верхняя граница)
        is_bottom: True если это нижняя строка ценника (нужна нижняя граница)
    """
    # 1. Сначала объединяем ячейки
    ws.merge_cells(start_row=start_row, start_column=start_col, end_row=end_row, end_column=end_col)
    
    # 2. Получаем ссылку на объединённую ячейку
    cell = ws.cell(row=start_row, column=start_col)
    
    # 3. Определяем стили границ
    top_style = 'thick' if is_top else None      # Верхняя граница
    bottom_style = 'thick' if is_bottom else None  # Нижняя граница
    left_style = 'thick'   # Левая граница (всегда)
    right_style = 'thick'  # Правая граница (всегда)
    
    # 4. Применяем границу к объединённой ячейке как к единому целому
    cell.border = Border(
        left=Side(style=left_style),
        right=Side(style=right_style),
        top=Side(style=top_style),
        bottom=Side(style=bottom_style)
    )
```

**Ключевой момент:** Границы применяются **один раз** к объединённой ячейке (`ws.cell(row=start_row, column=start_col)`), а не к каждой ячейке в цикле.

#### 2. Применение границ к 4 строкам ценника

```python
# 1. Организация (верхняя строка) - жирная рамка СВЕРХУ и по бокам
apply_border_to_merged_range(base_row, base_col, base_row, base_col+3, 
    is_top=True, is_bottom=False)

# 2. Наименование товара (средняя строка) - БЕЗ границ внутри ценника
apply_border_to_merged_range(base_row + 1, base_col, base_row + 1, base_col+3, 
    is_top=False, is_bottom=False)

# 3. Цена (средняя строка) - БЕЗ границ внутри ценника
apply_border_to_merged_range(base_row + 2, base_col, base_row + 2, base_col+3, 
    is_top=False, is_bottom=False)

# 4. Дата (нижняя строка) - жирная рамка СНИЗУ и по бокам
apply_border_to_merged_range(base_row + 3, base_col, base_row + 3, base_col+3, 
    is_top=False, is_bottom=True)
```

**Логика:**
- **Верхняя строка** (организация): `is_top=True` → жирная верхняя граница + боковые
- **Средние строки** (товар, цена): `is_top=False, is_bottom=False` → только боковые (от объединённой ячейки)
- **Нижняя строка** (дата): `is_bottom=True` → жирная нижняя граница + боковые
